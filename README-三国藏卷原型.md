## 本地运行

可以直接双击 HTML 文件，也可以在输出目录启动静态服务器：

```powershell
python -m http.server 8765
```

然后打开：

```text
http://localhost:8765/sanguo-cangjuan-prototype.html
```

## 后期替换卡图

当前卡牌使用 `cardart` 的 CSS 渐变和汉字占位。后期可以在 `cards` 数据中增加 `art` 字段，再把 `.cardart` 改成 `<img>`，不需要重写抽卡、图鉴或事件逻辑。
