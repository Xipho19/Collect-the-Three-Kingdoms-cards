# 逐鹿中原 · PVE 爬塔关卡设计

## 一、定位

用「逐鹿中原」替换现有军机台，作为常驻 PVE 爬塔模式：

- 每层 1 场 3v3 战斗
- 敌方阵容提前固定，不随机
- 我方从卡册选 3 名武将，可每层更换
- 胜利晋级下一层，失败可无限重试
- 层数越高，敌方属性越高，推动玩家抽卡、升阶、凑羁绊

## 实施进度（阶段 1）

- 已实现：30 层固定敌人、3v3 战斗、选人/换人、失败无限重试、首通奖励、推荐阶位
- 已实现数值：1–10 层沿用原公式；11–29 层非首领 560 +（层数−10）×15，首领 1863 +（层数−10）×18；敌方生命 = 攻击 ×5（首领 ×5.2）
- 已实现：敌方英雄复用卡面与技能名；目前仅敌方攻击类技能参与结算
- 未实现：扫荡、借将、赛季重置、自选包

## 二、核心循环

```
选择 3 名武将 → 查看敌方阵容/推荐星级 → 选择一次本层指令 → 自动战斗 → 胜利
      ↑                                                        ↓
      └──────────── 失败：调整阵容/升阶后重试 ←──────────────┘
```

- 每层战斗独立，生命值不跨层保留
- 已通关层可扫荡，不再重复战斗
- 首次通关发奖励，重复挑战只发少量铜钱

## 四、每层敌方属性

### 1. 目标战力

以 ★1 三人组约 **500 战力**、5 冠约 **645 战力**为基准：

| 层数 | 目标敌方战力 | 推荐我方星级 |
|---|---|---|
| 1 | 420 | ★1 |
| 5 | 450 | ★1–★5 |
| 10 | 488 | ★5 |
| 15 | 526 | ☾4 |
| 20 | 564 | ☀2 |
| 25 | 602 | ♛1 |
| 30 | 640 | ♛5 |

公式：

```text
目标战力 = 420 + (层数 - 1) × 7.586
```

### 2. 敌方单位属性

- 敌方使用对应英雄的 ★1 基础三维
- 统一乘以层数系数：

```text
层数系数 = 目标战力 / 500
```

- 敌方生命 = 攻击 × 6
- 每 5 层首领额外 +5% 生命，不额外加攻击
- 敌方技能按玩家技能的 **85%** 效果结算

### 3. 羁绊规则

- 当前版本：羁绊只看玩家是否拥有对应武将，**不需要上阵**，多组羁绊可同时生效
- 加成公式：基础值 + 成员平均星级 ×3%（四舍五入），例如桃园结义全员 ★1 +5%、全员 ★5 +8%
- 加成类型：攻击（桃园结义/江东火线/五虎上将/江东基业/河北双雄）、暴击（魏之奇谋）、生命（隆中求贤）、受伤降低（江东都督/虎卫）、伤害加成（凤仪亭/魏之谋主）
- 敌方单位不触发羁绊；数值已统一计入目标战力

## 五、玩家规则

- 每层选 3 名已拥有武将，可重复使用同一武将
- 每层开始前可调整阵容、查看敌方技能
- 战斗开始前选择一次「本层指令」：突击 / 固守 / 用计；之后整层自动战斗并自动选择目标
- 每次攻击/受击显示伤害数字与特效，生命值逐次扣除
- 每层独立满血开局
- 失败无惩罚，可无限重试
- 已通关层可扫荡，扫荡不消耗次数

## 六、奖励设计

| 节点 | 奖励 |
|---|---|
| 每层首通 | 铜钱 + 残卷，层数越高越多 |
| 每 5 层首领 | 额外招募券 ×1、残卷 |
| 每 10 层 | 自选武将包（3 选 1，优先未拥有/可升阶） |
| 每 30 层通关 | 限定名场面卡、称号、赛季头像框 |
| 每日扫荡 | 按已通关最高层发放铜钱，设置每日上限 |

奖励目标：

- 首通奖励足够支撑每 5 层一次十连
- 自选包优先给“差一张升阶”的武将，直接推动升阶
- 扫荡提供日常铜钱，避免重复手打

## 七、防卡关

- 失败界面显示：敌方剩余血量、我方伤害差、推荐提升方向
- 推荐提升优先级：
  1. 武将升阶（点击直达详情）
  2. 调整位置/羁绊
  3. 更换克制技能
- 同一层失败 3 次后，解锁「借将」：可租借一名系统武将打一次，不消耗资源
- 每周首次通关失败不扣扫荡次数

### 结论

**不需要新增静态美术资源。**

- 32 位武将卡面、9 个黄巾敌人立绘、张角卡图已经覆盖 30 层
- 敌方英雄与玩家复用同一张卡面，没有单独的“敌方版本”
- 张宝使用 `zhangbao.webp`，张角 Boss 使用武将卡图
- 如果希望敌方英雄有红色/暗色区分，可以用 CSS 滤镜，不需要新图

只有在以下情况才需要补图：

- 想给黄巾敌人加入攻击/受击/死亡动画（当前只有静态立绘）
- 想给敌方英雄单独绘制“敌将版”卡面
- 后续新增华雄、黄巾渠帅等不在现有资源内的角色

## 九、技术落地建议

### 1. 数据结构

```js
const towerFloors = [
  { floor: 1, chapter: '黄巾之乱', enemies: ['huangjin_daobing','huangjin_qishou','huangjin_shushi'] },
  { floor: 5, chapter: '黄巾之乱', boss: true, enemies: ['zhangbao','fushui_shushi','zhang_jiao'] },
  // ...
];
```

- 英雄敌人用卡牌 id
- 黄巾敌人用现有 minion id
- 每层可附加 `modifier`（例如“敌方生命 +10%”）

### 2. 战斗复用

当前 `resolveJourneyRound` 与 `state.journey` 耦合，需要先抽成通用战斗：

- `createBattle(allies, enemies, options)`
- `resolveBattleRound(battle)` → 返回胜负
- `renderBattle(battle, options)`
- 游历与逐鹿各自处理奖励、节点和存档

### 3. 存档

```js
state.tower = {
  season: 1,
  floor: 1,
  best: 0,
  cleared: [],
  sweepDay: '',
  sweepCount: 0
};
```

- 通关记录按赛季保存
- 赛季重置后保留最高层称号
- 旧存档默认从第 1 层开始

## 十一、风险

- 当前 ★1→5 冠综合提升约 29%，30 层难度只能做到“5 冠勉强通关”；如果希望升阶成为硬门槛，需要扩大 ★1 到 5 冠的属性差
- 敌方英雄复用玩家卡面，视觉上可能缺少“敌方感”；可加暗色/红色滤镜
- 30 层固定阵容会被玩家快速抄作业；建议每赛季轮换 30% 阵容或加层间词条
